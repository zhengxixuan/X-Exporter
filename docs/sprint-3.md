# Sprint 3 — 抛光与健壮性

## 完成内容
- Thread 抓取体验：提供实时进度 toast，展示已抓取条数与滚动尝试次数，结束时给出完整/部分提示。
- 抓取管线：`collectThreadTweets` 支持进度回调，强化 DOM 解析以确保引用与图片数据不会串到外层。
- Poster 稳定性：背景页增加跨域图片缓存（内存 + `chrome.storage` 持久化 + LRU 清理），内容端在导出前预加载并处理加载态。
- 错误处理：Toast 与日志覆盖抓取错误，并在背景页/缓存读写失败时输出警告。
- 单元测试：新增 `threadCollector` 集成测试覆盖进度回调与多推文收集。
